
# AutoClickerVIP iOS

AutoClick VIP - iOS application.

## Features

- SwiftUI interface
- Click counter
- Click interval settings
- Repeat mode
- Statistics

## Build

Open GitHub Actions.

Select Xay dung AutoClick VIP.

Click Run workflow.

Download AutoClickerVIP-IPA from Artifacts.

## Requirements

- Xcode
- XcodeGen
- iOS 16+
