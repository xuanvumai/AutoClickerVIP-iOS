
# Auto Clicker VIP iOS

Auto Clicker VIP for iPhone.

## Features

- Dark purple interface
- Application selection
- Open selected applications
- Single Click interface
- Multi Click interface
- Slide Up interface
- Auto Tool interface
- Speed settings
- Click counter

## Technology

- Swift
- SwiftUI
- Xcode
- Node.js 24
- GitHub Actions
- XcodeGen

## Build

1. Install Xcode.
2. Install XcodeGen.
3. Run xcodegen generate.
4. Open AutoClickerVIP.xcodeproj.
5. Configure Apple signing.
6. Build the application.

## Important

iOS does not allow ordinary applications
to inject automatic taps into other apps
or create unrestricted Android-style overlays.

The current Start button is a UI control,
not a cross-app auto-click engine.
